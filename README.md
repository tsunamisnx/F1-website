# Формула 1 — информационный сайт

Современный веб-сайт о Формуле 1 с удобной навигацией, интерактивными элементами и адаптивным дизайном.

## Основные возможности

* 🏎️ Информация о гонщиках и их статистике
* 🏁 Информация о командах
* 📅 Календарь Гран-при
* 📰 Раздел с новостями
* 🗺️ Информация о трассах и предстоящих гонках
* ⏱️ Информация о следующем Гран-при
* 🎨 Современный тёмный интерфейс
* ✨ Анимации и интерактивные элементы
* 📱 Адаптация под компьютеры, планшеты и мобильные устройства

## Технологии

* HTML5
* CSS3
* JavaScript
* SVG
* Адаптивная вёрстка

## О проекте

Проект создан как концепт современного информационного сайта о Формуле 1.

Основная задача проекта — объединить информацию о гонщиках, командах, календаре и новостях в одном современном и удобном интерфейсе.
